# Scenario pack: financial-filings

对比任意上市公司集合的招股书 / 年报财务数据。结构已由一次真实运行验证
（2 家港股上市公司 × 招股书 + 首份年报，4 对象，合并判定 PASS，见仓库
`examples/` 与该 run 的报告版式）。

## Targets

一个对象 = **一家公司 × 一份披露文档**（doc_type: `annual_report` |
`prospectus` | `interim`）。清单字段：

- `slug` — 稳定标识（建议 `<公司>-<文档类型>-<期间>`，如 `minimax-annual-fy2025`）
- `company` / `ticker` / `doc_type`
- 已知来源 hint（可选，能显著提高 worker 命中一手来源的概率）

## Fields

```
company, ticker, doc_type, report_period, revenue, revenue_yoy, gross_margin,
net_loss, adjusted_net_loss, key_segments, historical_series, risks, source_urls
```

## Worker prompt variant（叠加在基础模板之上）

- **一手来源优先级**：交易所披露原文 PDF（如港交所披露易）> 公司官方公告 >
  ≥2 家权威财经媒体交叉印证；仅单一来源支撑的字段必须注明。
- **数值字段必须带币种与单位**（如 `"79.038M USD"` / `"7.24亿元 RMB"`）；
  不同公司报告货币可能不同，禁止混算。
- **IFRS 口径与经调整口径分开填**，差额原因（如优先股公允价值变动）写进
  字段备注；对比经营趋势必须用经调整口径。
- 查不到写 `null`；推算值必须以 `(estimated)` 结尾，禁止伪装成披露值。

## Report layout（Stage 5）

1. 核心对照表（最新期，双币种并列 + 近似换算列，换算假设显式标注）
2. 历史轨迹表（收入 / 毛利率 / 经调整净亏损，按年度）
3. 差异要点（≤4 组，每组一个"表 vs 里"的判断）
4. 风险对照
5. 口径与局限说明（推算值、来源层级、换算假设）

## Pitfalls（来自真实 run 的教训）

- **媒体会混用口径**：某媒体的"净亏损 17.5 亿"实为经调整口径（招股书净亏损
  口径是 23.58 亿）——两个口径都必须抽取并分开呈现。
- **"毛利率转负"类标题可能只适用单一业务分部**——整体口径与分部口径分开核，
  分部口径单来源时要标注未交叉验证。
- **上市当期 IFRS 亏损会被优先股公允价值变动严重放大**（本例近 16 亿美元）——
  对比经营健康度必须用经调整口径，报表口径只说明会计影响。
- **货币不同（USD vs RMB）必须显式标注换算假设**，换算列只作量级参考。
- 历史序列来自招股书、最新期来自年报——两份文档口径衔接处要在报告中注明。
